# CARBOLAB
O CARBOLAB é uma plataforma educacional desenvolvida para apresentar a assistente virtual Kimberly IA, criada para auxiliar estudantes nos estudos de Biologia e Química. O projeto oferece interação inteligente, simulados e suporte educacional em uma interface moderna, responsiva e acessível para desktop e dispositivos móveis.

# Funcionalidades
* Apresentação visual da Kimberly IA com identidade própria
* Integração com chatbot educacional via Typebot
* Banco de questões voltado para vestibulares e ENEM
* Área de simulados para prática dos conteúdos
* Sessão explicativa de como utilizar a plataforma
* Layout responsivo para desktop e mobile
* Navegação intuitiva e moderna
* Área de acompanhamento de desempenho dos estudantes
* Interface temática voltada para Biologia e Química

# Integração com o Chatbot

A assistente virtual Kimberly IA foi integrada à landing page através da plataforma Typebot. O chatbot pode ser acessado diretamente pelo menu principal da aplicação, permitindo que os usuários conversem com a IA em tempo real.

Como funciona:

1. O usuário acessa a landing page do CARBOLAB
2. Clica no botão “IA Kimberly”
3. O chatbot é aberto via Typebot
4. O usuário pode tirar dúvidas e receber auxílio nos estudos

Link do chatbot:
https://typebot.co/kimberly-dvpdvs2

# Desafios e Aprendizados

Durante o desenvolvimento do CARBOLAB, a equipe enfrentou desafios relacionados principalmente à organização da interface, responsividade da landing page e integração do chatbot Kimberly IA com a plataforma. Foi necessário adaptar elementos visuais para diferentes tamanhos de tela, garantindo uma experiência acessível tanto em computadores quanto em dispositivos móveis.

Outro desafio importante foi estruturar uma interface intuitiva e visualmente atrativa, capaz de transmitir a proposta educacional do projeto de forma clara e moderna. Além disso, a equipe precisou trabalhar com organização de arquivos, padronização de código e documentação do projeto no GitHub através do README.

O desenvolvimento do projeto contribuiu significativamente para o aprimoramento de habilidades técnicas e interpessoais, como trabalho em equipe, divisão de tarefas, comunicação e resolução de problemas durante o processo de desenvolvimento.
